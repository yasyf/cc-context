**Releases.** Tagging `v*` triggers `.github/workflows/release.yml`, which runs goreleaser to build the binaries, cut a GitHub release, then render `.github/formula/ccx.rb.tmpl` and publish the Homebrew formula to `yasyf/homebrew-tap`. The version comes from the tag, and `plugin/.claude-plugin/plugin.json` is never bumped by hand. The release's `descriptor` job renders `plugin/bin/ccx.binrun` for the released version and sets the manifest to match in one `chore(release): sync ccx.binrun + manifest to vX.Y.Z` commit on `main`, then dispatches `ci.yml` and `guides.yml` against it. CI's `descriptor-agreement` job asserts the manifest and descriptor versions are equal, so a manifest bumped by hand fails every CI run until the release lands. A `smoke` job validates the released `darwin_arm64` tarball end to end, exercising `ccx exec` and `ccx format`. The release refuses to run unless the tagged commit is on `main` — tag a merged commit (e.g. `git tag vX.Y.Z origin/main`), not a feature branch. One-time setup: a `HOMEBREW_TAP_TOKEN` repo secret with push access to the tap.
